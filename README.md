# slide-skills

Reusable slide-building skills. Give a skill's `SKILL.md` to ChatGPT or a code agent in VS Code, then ask for a slide by type.

## Skills

| Skill | Slide types |
|---|---|
| [`status-slides`](skills/status-slides/SKILL.md) | `status-table`, `scorecard`, `metrics-table`, `proposal-flow` |

## Usage

> Using the attached SKILL.md, build a **scorecard** slide titled "…" from the attached screenshot.

All numbers come from what you attach. Missing values show as `[__]`.
